# Haneen Math

تطبيق مذاكرة الماث لحنين، للصف الثاني الابتدائي، الفصل الدراسي الأول.

## التشغيل على GitHub Pages
1. ارفعي كل الملفات الموجودة في هذا المجلد إلى المستودع، مع الحفاظ على مجلد `assets`.
2. من المستودع افتحي: Settings ← Pages ← Source: `Deploy from a branch` ← `main` / `root` ← Save.
3. بعد دقيقة يعمل التطبيق على الرابط: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

ملاحظة: افتحي التطبيق من الرابط، لا بالنقر المزدوج على `index.html`، لأن بعض الملفات تُحمَّل من الخادم.
