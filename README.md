# HANEEN · مذاكرة حنين

الصف الثاني الابتدائي · الفصل الدراسي الأول

## التنظيم

| الفولدر | المادة | التطبيق | الامتحانات |
|---|---|---|---|
| `math/` | ماث | Haneen Math | `math/exams/` |
| `arabic/` | عربي | لغتي الجميلة | `arabic/exams/` |
| `english/` | إنجليزي | Learn with Miss Walaa | `english/exams/` |
| `religion/` | دين | التربية الدينية | `religion/exams/` |

- `index.html` في الروت هي الصفحة الرئيسية وفيها لينك كل تطبيق وكل امتحان.
- كل مصدر امتحانات في فولدر لوحده، وكل امتحان في ملف لوحده باسمه.
- في كل فولدر مصدر ملف `00` فيه الملف الأصلي كامل زي ما هو.

## الرفع على GitHub Pages

1. ارفعي كل اللي جوه فولدر HANEEN على ريبو HANEEN (مكان الملفات القديمة).
2. Settings ← Pages ← Deploy from a branch ← `main` / `root`.
3. اللينكات:
   - الرئيسية: `https://zksp2.github.io/HANEEN/`
   - ماث: `https://zksp2.github.io/HANEEN/math/`
   - عربي: `https://zksp2.github.io/HANEEN/arabic/`
   - إنجليزي: `https://zksp2.github.io/HANEEN/english/`
   - دين: `https://zksp2.github.io/HANEEN/religion/`
